# Goal: Простой todo-app

## Что делаем
Веб-приложение для управления списком задач. Минимальный, но рабочий.

## Для кого
Личное использование. Без авторизации, без облака, без синхронизации.

## Скоуп MVP
- Создать задачу
- Отметить задачу выполненной
- Удалить задачу
- Сохранить состояние между перезагрузками страницы (localStorage)

## Не входит в MVP
- Авторизация
- Категории/теги
- Дедлайны
- Мобильная версия
- Синхронизация между устройствами

## Технический минимум
- Один HTML файл или простой SPA
- Vanilla JS или минимальный фреймворк (на усмотрение build-агента)
- Запускается локально: `python -m http.server` или аналог

## Готово, когда
- Все 4 действия работают в браузере
- Состояние переживает reload
- verify.sh проходит
