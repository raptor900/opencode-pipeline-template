# Sprint 1: MVP — todo-list

## Цель
Работающий todo-list в одном HTML-файле с 4 действиями и сохранением в localStorage.

## Критерии готовности

- [ ] Открыть `code/index.html` в браузере → видно пустое состояние
- [ ] Ввести текст в поле и нажать Enter → задача появляется в списке
- [ ] Кликнуть чекбокс → задача отмечается выполненной (визуально зачёркнута)
- [ ] Кликнуть "×" рядом с задачей → задача удаляется
- [ ] После перезагрузки страницы все задачи и их состояние сохраняются
- [ ] Если задач нет — видно сообщение "Нет задач" или эквивалент
- [ ] `bash scripts/verify.sh` exits 0
