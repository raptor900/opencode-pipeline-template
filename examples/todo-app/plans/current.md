# План: Todo App

## Цель
Минимальный todo-list для личного использования. Локально, без бэкенда.

## Спринты

### Sprint 1: MVP — создание, выполнение, удаление, persist
**Что:** один HTML-файл с todo-list. Vanilla JS. Сохранение в localStorage.
**Зачем:** работающий прототип для проверки pipeline.
**Готово, когда:** 4 действия работают, состояние переживает reload.

### Sprint 2: UX polish (backlog)
**Что:** категории, фильтры, счётчики.
**Зачем:** удобство.
**Готово, когда:** (ещё не детализировано)

### Sprint 3: Деплой (backlog)
**Что:** GitHub Pages или аналог.
**Зачем:** доступ с любого устройства.

## Зависимости
Sprint 1 → Sprint 2 → Sprint 3 (последовательно).
